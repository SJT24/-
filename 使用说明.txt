善鸡通AI（shanjitong）社交页面

使用方法
1. 解压后用浏览器打开 index.html 即可（需要联网加载样式库和字体）。
2. 数据只保存在这台设备的浏览器里。换设备或清除浏览器数据前，
   请在 设置 -> 导出数据 里备份，需要时再导入。

放到公网（静态托管，无需构建）
- 把整个文件夹上传到 Vercel / Netlify / Cloudflare Pages / GitHub Pages 即可。
- 这个版本是单机版：每个访问者看到的是自己浏览器里的数据，不会互相共享。
  要做成多人共用，需要用之前提供的 Supabase 版本（shanjitong-ai-project.zip）。
